# Backend — описание и стадии

## Что это за приложение

Это учебный мессенджер с публичными чатами:
- **Чаты видны всем** (без ограничений доступа на текущем этапе).
- **Любой может создать чат**, и это увидят остальные клиенты.
- **Любой может читать/писать** сообщения в любом чате.
- **Пользователь “заходит” по имени** (упрощенный логин без паролей и токенов).
- **Сообщения передаются только через WebSocket** (`socket.io`), чтобы получать их в реальном времени.

Backend отвечает за:
- REST API для логина/логаута и CRUD чатов
- WebSocket для получения истории и доставки новых сообщений
- In-memory store (без базы данных) с хранением последних 50 сообщений на чат
